# nightwb — 夜间混光场景的光源估计与色适应（纯 Go，无相机 SDK）

钠灯（低色温、偏橙）、霓虹（高饱和单色光）和摄影棚泡（接近日光）混合时，
单一全局 Kelvin 白平衡无法同时让肤色和灰卡中性。本工具从画面中的中性样本
估计 illuminant，输出保守与激进两套色适应结果，并记录颜色不可恢复的区域。

## 方法

1. **线性化**：sRGB 传递函数逆变换到线性光，标记源图削波（通道达编码最大值）
   与压暗（通道为 0）像素；按像素实际位深（8/16 bit）判定。
2. **中性样本筛选**：低色度、中间调、未削波的像素作为候选；近中性样本权重高，
   更宽的色度池以低权重保留，用于发现双光源。
3. **稳健聚合**：对候选色度做加权中位数（对霓虹/单色反射物鲁棒），并用
   gray-world 与 white-patch 交叉校验；分歧大时降低置信度并向 gray-world 融合。
4. **混光检测**：在（亮度, 红-青色度）二维做加权 k-means（k=2）。中性表面在
   不同光源下归一化色度相同，光源分裂由亮度轴承载；检出双模式时报告两个簇
   （各自 CCT/权重），全局适应以主导簇为准。
5. **回退**：中性样本不足（单色反射画面）时显式回退 gray-world，置信度降到
   0.15 并对全帧打低置信度标记。
6. **色适应**：Bradford von Kries，把估计光源白点映射到 D65。
   - `conservative`：强度 0.55，高光区按亮度膝部向单位矩阵回退，保护肤色与
     高光，保留可预期的轻微残余色偏。
   - `aggressive`：强度 1.0，全帧单一矩阵，最大化中性化，越界与高光伪影更多。
7. **不可恢复区域**（16-bit mask，按位标记）：通道削波、阴影压暗、适应后超出
   [0,1] 色域、混光争议区、低置信度区。mask 分两张：源端缺陷与适应端缺陷。

## 用法

```bash
go run ./cmd/nightwb -in photo.png -out wb_out
# 生成内置合成混光测试图（含灰卡、单色反射、削波带）
go run ./cmd/gendemo /tmp/demo.png
```

输出：

- `conservative.png` / `aggressive.png`：两档适应结果（8-bit sRGB）
- `mask_source.png` / `mask_adaptation.png`：16-bit 灰度标记图
- `report.json`：illuminant（RGB/XYZ/CCT/tint/置信度/簇/警告）、曝光统计、
  各方案越界比例、不可恢复区域比例与说明

## 测试

```bash
go test ./... -race -cover
```

覆盖：混光双簇检测、单色反射回退、过曝削波/欠曝压暗、灰卡中性化（保守档
残余色偏严格大于激进档）、CCT 排序、解码削波标记与 mask PNG 位保持。
