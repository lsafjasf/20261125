## 透明视频导出器

纯 Go 标准库实现，不使用任何图像或视频第三方包。导出器在自定义 `TVID`
原始 RGBA 容器中写入三帧：

- 源帧：保留当前 `straight` 或 `premultiplied` Alpha 表示。
- 黑底测试帧：将源帧合成到不透明黑色背景。
- 白底测试帧：将源帧合成到不透明白色背景。

切换 Alpha 模式时会同步转换像素并更新模式元数据，避免只改标签。导出先写入
同目录临时文件，重新解码并核对元数据、帧顺序和像素颜色，校验通过后才原子替换
目标文件；失败时保留上一版成功文件。

运行验证：

```sh
go test ./...
go vet ./...
```
