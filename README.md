# ACES AP0 D60 到 D50 内部流程的白点适配基准

这个 Go 模块比较三种将 ACES AP0 / D60 XYZ 送入 D50 内部流程的方式：

- `keep_xyz`：不做白点适配，保留 XYZ 数值，并要求元数据继续声明原始白点。
- `bradford`：在 Bradford cone-response 空间独立缩放后回到 XYZ。
- `von_kries`：在经典 Hunt-Pointer-Estévez / Von Kries cone-response 空间独立缩放后回到 XYZ。

## 运行

```bash
go test ./...
go vet ./...
go run ./cmd/whitepoint-benchmark
go run ./cmd/whitepoint-benchmark -json > artifacts/whitepoint-benchmark.json
go run ./cmd/whitepoint-benchmark -json -all-results > /tmp/full-results.json
```

## 测试样本

基准共 144 个确定性样本，不用平均 RGB 作为判断依据：

- 5 组照明：2856K、3500K、5000K、6500K、合成等功率白光，共 55 个解析光谱积分样本。
- 中性色：18%、50%、90% 反射率，每组照明各一个。
- 肤色：浅、中、深三种平滑光谱反射模型，每组照明各一个。
- 高彩度光谱色：红、绿、蓝、黄、青五个窄带反射模型。
- AP0 真实色域：3 条原色三角边、7 个插值点和 3 档向内偏移，共 63 个样本。
- AP0 编码压力：8 个立方体顶点、12 条棱中点、6 个面中心。

主要误差是 D50 Lab 下的 CIEDE2000 ΔE2000。Bradford 作为当前常见 D50 / ICC 工作流的参考方法，方法间差异是相对 Bradford 输出计算；报告同时给出白点 ΔE2000、分组 p95/max、照明分组、XYZ 绝对残差和 AP0 相对残差。光谱样本使用无外部数据依赖的解析 CIE 1931 近似 CMF，定位为确定性压力测试，不替代官方 CIE 数据表。默认 JSON 保存汇总和最差样本，加 `-all-results` 可导出全部 144 个逐样本结果。

## 关键结果

| 方法 | 白点 ΔE2000 | 相对 Bradford 均值 | p95 | 最大 | 中性色均值 | 肤色均值 | 色域边界最大 | 往返最大 ΔE2000 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| `keep_xyz` | 10.7609 | 5.8076 | 16.6415 | 25.1730 | 8.7535 | 5.1462 | 25.1730 | 8.11e-14 |
| `bradford` | 0 | 0 | 0 | 0 | 0 | 0 | 0 | 1.69e-13 |
| `von_kries` | 0 | 2.5310 | 9.4942 | 11.1257 | 约 7.61e-14 | 0.5756 | 11.1257 | 1.73e-13 |

往返测试没有引入裁剪或 gamut mapping，只测量线性矩阵正反向组合。三种方法在浮点层面都可逆：

- 最大 XYZ 绝对残差不超过约 `6.66e-15`。
- 最大 AP0 相对残差不超过约 `4.85e-14`。
- 最大往返 ΔE2000 不超过约 `1.73e-13`，实际可视为零。

若后续把结果写入有边界的 RGB 编码并执行裁剪，误差将来自 gamut mapping / clipping，而不是这些线性矩阵的往返。

## 方法差异与选择依据

### 保持 XYZ

保持 XYZ 的数学可逆性很好，但 D60 白点不会变成 D50。内部 D50 Lab、软打样、白平衡或任何假设 D50 reference white 的操作会把这个白点差解释成颜色偏移。该基准中中性色平均达到 8.75 ΔE2000，肤色平均 5.15 ΔE2000，边界样本最大 25.17 ΔE2000。

只有在内部管线能完整携带白点元数据，并且所有后续模块都显式按原白点解释 XYZ 时，才应选择它。

### Bradford

Bradford 精确把 ACES D60 白点映射到 D50，并在本测试中作为参考输出。它对中性灰保持稳定，高彩度和近边界样本的变换更可控，也符合大量 D50 ICC、色彩管理和图像管线中的常见实践。

对于“内部规范已经固定为 D50 XYZ，同时希望减少中性色和肤色偏色”的场景，推荐默认选择 Bradford。

### Von Kries

经典 Von Kries 同样能精确映射白点，中性灰几乎无差，但它使用不同的 cone-response 矩阵。与 Bradford 相比，本测试中肤色平均有 0.58 ΔE2000，真实 AP0 色域边界最大有 11.13 ΔE2000。差异通常低于保持 XYZ，但在接近边界的高饱和色上不可忽略。

当组织已有 Von Kries / HPE 规范、硬件显示模型或外部接口要求该变换时，应选择 Von Kries；否则没有必要仅为 D50 内部流程从 Bradford 切换到它。

## 结论

推荐在该 D50 内部流程中使用 Bradford：它能消除 D60/D50 白点错配，中性色和肤色结果稳定，近色域边界样本的方法间差异最小。保持 XYZ 只适合保留原白点语义的显式场景；Von Kries 适合兼容既有标准或硬件模型。三种方法的纯线性往返误差都接近机器精度，观察到的色彩差异来自适配模型本身，不是不可逆数值损失。
