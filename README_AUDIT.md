# 对白录音短水印片段审计工具（Go 标准库）

检测对白录音中是否混入重复的短水印片段，并把重复证据与两类易混现象区分开：

- `watermark_repeat` 真实重复：注入的同一短片段在多个离散时刻出现，增益稳定、不衰减、不锁块；
- `natural_echo` 自然回声：覆盖全片的弥散延迟链，呈单调 RMS 衰减，无离散事件聚集；
- `codec_ringing` 编码回响：短周期、严格对齐变换块边界、正负滞后对称、伴随块边界阻尼瞬态；
- `rejected` 证据未超过置乱反例或判别量互相冲突，如实标记为不成立，不强行下结论。

## 证据保全原则

全程**不做任何降噪、谱减、平滑或幅度归一化**。唯一的信号处理是：

- Hann 加窗（仅用于分帧分析，不改原始样本）；
- 零阈值 FFT 频段掩膜（`dsp.Bandpass`），用于在候选频段内隔离证据，原始缓冲永不修改；
- 16-bit WAV 写出时的峰值限幅只存在于合成测试工具。

## 方法流水线

1. **WAV 读取**：PCM 8/16/24/32-bit 与 IEEE float32/64，多声道算术平均降混，保留原始相对幅度。
2. **候选频段**：6 个对数分布频段（80 Hz–9 kHz），逐带分析。
3. **窗函数分帧**：Hann 窗，1024 样本帧、512 跳；倒谱使用 32768 样本长窗以容纳回声谐波滞后。
4. **倒谱峰**：功率倒谱局部峰 + 突出度，聚合为候选滞后；rahmonic（整倍数 quefrency）作为周期结构旁证。
5. **相邻片段对齐**：能量 onset 事件 → 候选片段长度（256/512/1024/2048）局部扫描 NCC 对齐 → 团（clique）校验，拒绝传递式巧合链；非极大值合并跨长度/跨频段重复。
6. **三路滞后融合**：倒谱峰 + 帧能量包络自相关 + onset 间隔 + 显式变换块滞后，聚类去重。
7. **判别特征**：NCC 均值/峰值/高相关占比、增益比及变异系数、延迟链 RMS 衰减、块网格对齐、块内边界瞬态、±滞后对称、事件局部化比例、支撑覆盖率。
8. **反例（counterexample）**：每条结论都与“时间置乱窗口对照”比较——同滞后但第二窗取自随机远处非匹配位置，保持边际谱与电平、破坏时间结构；另按类别给出回声/回响/水印的竞争假设反例。
9. **置信区间**：对 NCC 做 Fisher-z 变换后 bootstrap（默认 1000 次）百分位 95% CI；增益比直接 bootstrap。

## 每条结论的必含字段

- 起止样本：`sample_range`（半开区间 `[start,end)`），水印另给每个副本的 occurrence 区间与对齐抖动；
- 置信区间：NCC 与增益比的 95% bootstrap CI；
- 反例：竞争假设类型、对照 NCC、判定阈值与对照样本区间；
- 全部判别特征与触发理由，决策完全可审计。

## 用法

```bash
# 生成带真值的受控测试录音（含 5 个水印副本、3000 样本回声、256 块回响）
go run ./cmd/wmsynth -out testdata/synth.wav -truth testdata/synth.truth.json

# 审计真实录音
go run ./cmd/wmdetect -in recording.wav -json report.json > report.txt
```

## 测试

```bash
go test ./...
```

端到端测试在受控信号上校验：水印族副本数与 CI、回声滞后（±60 样本）、无块伪影时不得误报回响，且每条结论必须带反例与非空样本区间。

## 标准库边界

仅依赖 Go 标准库（`math`、`math/rand/v2`、`encoding/binary`、`encoding/json`、`os`、`sort` 等）；FFT/倒谱/滤波/统计全部在 `internal/dsp` 与 `internal/detect` 内自行实现。
